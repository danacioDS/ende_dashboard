## Upgrades Implemented

### 1. Code Duplication Eliminated (~3000 lines removed)
**New module: `utils/`** with three shared components:

| Module | Purpose |
|--------|---------|
| `utils/data_loader.py` | `load_and_melt()`, `load_and_pivot_columns()`, `build_date_mapping()`, `parse_period_code()`, `resolve_data_path()` |
| `utils/charts.py` | `plot_line_evolution()`, `plot_entity_evolution()`, `plot_system_bars()`, `plot_participation_bars()`, `plot_comparison_lines()`, `show_sidebar_info()`, `show_price_sidebar_info()` |
| `utils/filters.py` | `date_range_slider()`, `filter_by_date()`, `entity_selectbox()`, `child_selectbox()` |

Each dashboard page was reduced from ~250-400 lines to ~70-100 lines, using a `CONFIG` dict.

**Before/after comparison:**
| Page | Before | After | Reduction |
|------|--------|-------|-----------|
| `energia_por_distribuidor.py` | ~440 lines | 102 lines | ~77% |
| `precio_energia_distribucion.py` | ~269 lines | 76 lines | ~72% |
| All 14 pages combined | ~4504 lines | ~1257 lines | ~72% |

### 2. Configuration File Added
**New file: `ende_config.yaml`** centralizing:
- Pipeline years (`start_year`, `end_year`)
- File paths and folder names for distribution and generation
- Entity column names (`AGENTE`, `CENTRAL`, `EMPRESA`, `TECNOLOGIA`)
- Extraction column indices and rename mappings per data type
- Dashboard title and layout settings
- CNDC base URL

### 3. CI/CD Pipeline Added
**New file: `.github/workflows/ci.yml`** with two jobs:
- **test** — runs on push/PR to main, matrix across Python 3.11/3.12, installs deps, lints with `ruff`, runs `pytest -v`
- **docker** — needs test to pass, builds Docker image on main branch

### 4. Modern Python Packaging
**New file: `pyproject.toml`** with:
- Project metadata (name, version, description)
- Dependencies (pandas, streamlit, plotly, etc.)
- Dev dependencies (pytest, ruff, mypy)
- Ruff config (line-length=100, py311 target)
- Pytest config (`testpaths = ["tests"]`)
- Mypy config (strict=false, ignore missing imports)

### 5. Tests Improved
- `tests/test_functions.py` — **deleted** (had failing path checks)
- `tests/test_scripts.py` — **new**, parametrized test for all ETL scripts, dashboard pages, and utility files
- `tests/test_utils.py` — **new**, tests for `build_date_mapping()`
- `tests/test_pipeline.py` — **expanded** with `TestDateMapping`, `TestParsePeriodCode`, `TestResolveDataPath` classes

### 6. Extraction Script Fixes
All `dis_03_*` and `gen_03_*` scripts now use `fnmatch` for file exclusion patterns. The `gen_03_extract__energia_columns.py` was fixed to use `"CENTRAL"` instead of `"AGENTE"` and `"Energía kWh"` instead of `"Energía MWh"`.

### 7. README Rewritten
`README.md` was updated with clearer architecture docs, mermaid diagram, test instructions, and Docker deployment guide.

### 8. Dockerfile Updated
Fixed CMD case and generally cleaned up comments.
